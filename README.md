# Adwait Palsule — Portfolio

A minimal, responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. No build step or dependencies are required.

## Deploy with GitHub Pages
1. Create a new public repository (for example, `adwaitpalsule.github.io`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Before publishing
- Confirm that all project descriptions and public-facing details are accurate.
- Add direct repository links where you want to showcase public source code.
- The badminton major project is intentionally not linked to a source repository, as its materials are not public.
- Add a downloadable resume PDF if desired.


The portfolio defaults to a light editorial canvas with dark project and experience cards. Use the header toggle to switch the full page between light and dark themes; your preference is saved in the browser.
